# 高德 MCP 接入指南（面向零基础用户）

本 Skill 用高德地图的 MCP 工具获取真实坐标、驾车距离和时长——这是防止"AI 编地名/编距离"的关键一步。没有它，行程里的每个地点都会标"未核验"。

## 第一步：判断你属于哪种情况

**情况 A：你完全没接触过高德开放平台** —— 从下面"完整注册流程"开始。

**情况 B：你已经在别的项目/工具里配过高德 key** —— 跳到下面"已有 key，只需加一段配置"。

---

## 完整注册流程（情况 A）

1. 打开 [lbs.amap.com](https://lbs.amap.com)，右上角注册/登录（支付宝扫码最快）。
2. 完成个人开发者实名认证（身份证 + 支付宝人脸识别，几分钟）。
3. 进入控制台 →「应用管理」→「创建新应用」，随便起个名字（比如"自驾攻略"）。
4. 在这个应用下「添加 Key」，**服务平台选「Web 服务」**（不是 Web 端 JS API，选错了后面调用会报权限错误）。
5. 复制生成的 Key（一串字母数字）。

拿到 Key 后继续下面"添加 MCP 配置"。

## 已有 key，只需加一段配置（情况 B）

如果你已经有一个"Web 服务"类型的高德 Key，直接跳到下面的配置步骤，不用重新注册。

## 添加 MCP 配置

Claude Code 的 MCP server 配置在 `~/.claude.json`。有两种接入方式，选一种：

**方式一：本地 npx（推荐，无需公网出口，key 不会出现在 URL 里）**

```json
{
  "mcpServers": {
    "amap-maps": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@amap/amap-maps-mcp-server"],
      "env": { "AMAP_MAPS_API_KEY": "你的Key" }
    }
  }
}
```

**方式二：高德官方托管 SSE（免装依赖，但 key 会拼在 URL 里）**

```json
{
  "mcpServers": {
    "amap-maps": {
      "type": "sse",
      "url": "https://mcp.amap.com/sse?key=你的Key"
    }
  }
}
```

⚠️ 方式二的 URL 本身就是凭证，不要截图分享、不要贴进聊天记录里；一旦泄露去控制台重置 Key。

**放在哪一层配置，决定这个 Skill 能在哪些地方用**：
- 放进某个项目目录对应的 `projects` 节点下 → 只在那个目录里生效
- 放进顶层 `mcpServers` 节点 → 任何目录启动 Claude Code 都能用（这个 Skill 属于个人工具，建议放顶层）

## 配置生效之后

MCP server 是会话启动时连接的，**改完配置要开一个新的 Claude Code 会话才会生效**，当前会话里改了也不会立刻可用。

新会话里，让模型试着调用一次 `maps_geo`（查"北京"）验证连通：
- 成功返回坐标 → 配置好了，可以正常使用本 Skill
- 报错/超时 → 检查：key 是否是"Web 服务"类型（不是"Web端(JS)"）、`AMAP_MAPS_API_KEY` 有没有拼错、npx 能不能正常联网下载包

## 免费额度

个人版高德 Key 有每日免费调用配额。一次 7-9 天的行程规划大约消耗 30-60 次调用（地理编码 + 路径规划 + POI 搜索），正常使用完全够用。
